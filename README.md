# RRCKI Mail

Корпоративный почтовый клиент RRCKI — frontend-прототип на React + TypeScript + Vite.

## Требования

- Node.js 20.19+ или 22.12+ (рекомендуется актуальный LTS)
- npm 10+

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (по умолчанию `http://localhost:5173`).

## Проверки и сборка

```bash
npm run typecheck
npm run build
npm run preview
```

## Что реализовано

- Трёхколоночный почтовый интерфейс, адаптация под узкие экраны.
- Папки, тестовые сообщения, поиск и фильтры.
- Выбор сообщения, непрочитанное состояние, звёздочки.
- Создание письма, ответ и пересылка (демо-сценарий, без реальной отправки).
- Переключение светлой/тёмной темы.
- Настройки/подключение аккаунта пока представлены как UI-заготовка.

## Важно

Сейчас это только frontend с демонстрационными данными. Он **не подключается** к Exchange, IMAP/SMTP или Keycloak и не отправляет почту. Не вводите реальные пароли. Следующий этап — определить API-контракт и создать серверный Mail API с защищённым хранением учётных данных.

## Предлагаемая следующая архитектура

- Web: React + TypeScript.
- Desktop: Tauri 2 поверх общей UI-кодовой базы.
- Mobile: Capacitor либо отдельная оболочка после проверки UX.
- Backend: Go REST API.
- Exchange 2016: адаптер EWS с проверенной схемой аутентификации.
- Универсальная почта: IMAP/SMTP адаптер.
- Корпоративный вход в приложение: Keycloak OIDC Authorization Code + PKCE.
